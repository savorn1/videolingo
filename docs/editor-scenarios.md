# Video editor scenarios

Step-by-step manual test cases for the video editor (`app/components/VideoClipEditor.vue` and its tab panels), grouped by tab. There is no browser test setup, so run these by hand after changing the editor. Rules and limits are in the "Video editor business rules" section of `CLAUDE.md`; the backend re-checks all of them.

Setup for every case: open a video you can edit (stored file, not a link) with a user that has WRITE permission on videos, then **Edit** → the tab named below. Use a video that is at least a minute long with a known frame size.

## Split

| #   | Scenario               | Steps                                                                                     | Expected                                                                                                                              |
| --- | ---------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| S1  | Split at the playhead  | Play to a moment, **Split at playhead** (or press `S`).                                   | The segment under the playhead becomes two; disabled within 0.1 s of an edge or outside any segment.                                  |
| S2  | Split evenly (presets) | Click **4 parts** on a video of known length.                                             | Four segments of equal length, no gaps, the last one running to the end; buttons above the allowed count are disabled with a tooltip. |
| S3  | Split evenly (custom)  | Type 7, press Enter or **Split**.                                                         | Seven equal segments; below 2 or above the limit the button is disabled; a line shows "7 parts × about M:SS each".                    |
| S4  | Split every N seconds  | Type `60` under "Or every".                                                               | A segment per minute; a remainder under 0.5 s joins the previous segment; counts above 20 are refused (button disabled).              |
| S5  | Edit segment times     | Retype a start or end in a row.                                                           | Accepted times reformat; an end before its start outlines the row in red with a message under it and disables Start split.            |
| S6  | Add / remove segments  | **Add segment**; remove one with X.                                                       | A new `0:00 → end` row appears; the last remaining segment cannot be removed.                                                         |
| S7  | Drag a shared cut      | Drag the handle between two touching segments; also focus it and press ←/→ (Shift = 1 s). | Both neighbours resize together and stay at least 0.5 s; the handle is wider on touch screens.                                        |
| S8  | Gaps                   | Move one segment's start later than the previous one's end.                               | "X of the video isn't in any segment and will be left out" appears; the split is still valid.                                         |
| S9  | Keyboard               | On the Split tab press `[` and `]`, then `S`.                                             | Selection moves between segments (video jumps to its start); shortcuts are ignored while typing in a field or inside a dialog.        |
| S10 | Reset and undo         | **Reset split**, then Ctrl/⌘+Z.                                                           | Segments go back to one full-length segment; undo restores them.                                                                      |
| S11 | Start a split          | **Start split** with 3 segments.                                                          | "Split queued — job #N"; Results later hold one clip per segment, titled "Segment N · start – end".                                   |
| S12 | Too many segments      | Try to exceed 20 (by typing a custom count or every N seconds).                           | Refused: custom Split disabled; manual rows show "At most 20 segments at a time".                                                     |
